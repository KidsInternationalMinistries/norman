# Norman's public pages

Published by Claude from Norman's project files. Served by GitHub Pages at https://kidsinternationalministries.github.io/norman/

- `talks/` — public slides, one folder per talk (e.g. `talks/Character-Calling-Conviction/`), shared code in `talks/common/`. The talk folder is the monitor (slides only), `present.html` is the password-protected presenter view (cues, key points, verses; no full scripts). The presenter's Next moves every open monitor through a public relay.
